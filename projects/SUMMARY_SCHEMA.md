# Project summary format

`projects/index.html` (the projects homepage) is generated by
[`scripts/generate_projects_index.py`](../scripts/generate_projects_index.py) from a `summary/`
subdirectory inside each project. To add a project to the homepage, create
`projects/<your-project>/summary/info.yml` plus any image files it references, then re-run the
generator (see [`scripts/README.md`](../scripts/README.md)).

A project directory with no `summary/info.yml` is simply skipped by the generator, so you can
keep draft/unlisted projects around without a summary.

## `summary/info.yml` fields

| Field               | Required | Type              | Description |
|---------------------|:--------:|-------------------|--------------|
| `title`              | yes | string | Project title, shown as the entry's heading. |
| `year`               | yes | int | Used to sort entries reverse-chronologically. |
| `short_description`  | yes | string | One to three sentences shown in the entry. |
| `thumbnail`           | yes | string | Filename of an image/GIF **inside this same `summary/` directory**. |
| `thumbnail_alt`       | yes | string | Alt text for the thumbnail. |
| `collaborators`       | yes | list of `{name, url}` | Include yourself too. `url` is optional (omit for no link). |
| `tags`                | no | list of strings | Shown as small pills under the description. |
| `links`               | no | list of `{label, url, icon}` | Buttons under the entry, e.g. Code / Report / Demo. `icon` is a Font Awesome class (defaults to `fas fa-link`). |
| `page`                | no | string | Project's entry HTML file, relative to the project directory. Defaults to `index.html`. |

## Example

```yaml
title: "JPEG Image Compression"
year: 2025
short_description: >
  A from-scratch DCT-based image and video compression pipeline: quantization, zigzag
  scanning, and Huffman coding, following the design of the JPEG standard.
thumbnail: thumbnail.png
thumbnail_alt: >
  An 8x8 grid of 64 two-dimensional DCT basis patterns, ranging from a flat gray square
  to fine checkerboards.
tags: [JPEG, DCT, Image Compression, Video Compression, Huffman Coding]
collaborators:
  - name: Roger Vendrell Colet
    url: https://www.linkedin.com/in/roger-vendrell-colet/
links:
  - label: Code
    url: https://github.com/rogervendrell/jpeg-image-compression
    icon: fab fa-github
```

Place the referenced `thumbnail` file (e.g. `thumbnail.png`) next to `info.yml` in the same
`summary/` directory — a still image, an animated GIF, or an SVG all work.
